# atv02-backend
 objetivo é permitir que clientes e barbearias realizem cadastro, login e agendamento de serviços como corte, barba ou combo, com escolha de data e horário.

## ✅ Implementação das Tarefas - UI

### Sprint 1 — Identidade Visual e Estrutura da Interface
- [x] Definir a identidade visual (paleta de cores, tipografia e logo)
- [x] Criar os protótipos das telas no Figma
- [x] Estruturar o projeto front-end com HTML, CSS e JavaScript
- [x] Criar componentes base (botões, campos de formulário, cabeçalho e rodapé)

### Sprint 2 — Telas de Acesso e Agendamento
- [x] Implementar a tela de login para clientes e barbearias
- [x] Implementar as telas de cadastro de cliente e de barbearia
- [x] Implementar a tela de esqueci a senha
- [x] Implementar a seleção de barbearia e de serviços (corte, barba ou combo)
- [x] Implementar a tela de agendamento com escolha de data e horário
